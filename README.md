I'm a cyber security graduate out of CQUniversity, cyber security as the major and app development as the minor. For the past six months I've been interning at insureKU, a Malaysian insurtech running the country's first end to end insurance and takaful aggregator, built under Bank Negara's fintech regulatory sandbox, so the security work there came with a regulator attached rather than a marking rubric.
